## Игра "Угадай число"

Это консольная игра на Python, в которой игрок(и) пытаются угадать случайное число. 
 Поддерживает четыре режима: классический, сложный, двойной и режим ознакомления с правилами.


## Требования:
* Python 3.0 и выше!


# Установка Termux:

* 1) pkg update
* 2) pkg upgrade
* 3) pkg install python3
* 4) pkg install git
* 5) git clone https://github.com/sir-darkk/random_game-py.git

# Установка на других системах:

* 1) git clone https://github.com/sir-darkk/random_game-py.git


# Запуск:
 
* 1) cd random_game-py
* 2) python3 random_game.py
